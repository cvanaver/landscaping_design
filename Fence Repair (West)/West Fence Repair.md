## 🔧 Tools

- Impact driver (T25 bit)
- Drill (or light use of impact)
- Kreg pocket hole jig + bit
- Reciprocating saw (metal blades, 14–18 TPI)
- Pry bar (thin + long)
- Clamps or spacer blocks
- Tape measure
- Level
- String line (+ optional line level)
- Circular saw or track saw (for ripping last picket)

---

## 🪚 Steps

### 1. Remove damaged components
- Cut nails between rails and posts (Sawzall)
- Remove bottom rails
- Remove bad pickets
- Avoid removing top 2x4 if possible (supports lattice)

---

### 2. Install new bottom 2x4 rail
- Measure post-to-post at install height
- Subtract 1/8"–1/4"
- Cut square
- Drill pocket holes in **rail only**
- Attach to posts with 2-1/2" Kreg screws

---

### 3. Install pickets
- Run string line across top
- Use spacers for consistent gaps
- Pre-drill near ends
- Screw pickets into **2x4 rails only**

---

### 4. Handle last picket
- Measure gap at top and bottom
- Rip to fit (track saw or circular saw)
- Install with cut edge toward post

---

### 5. Install fascia (1x4 rails)
- Attach on opposite side of 2x4 rails
- Screw through pickets into 2x4
- Do NOT attach fascia to posts

---

## 🧠 Key Principles

- Structure = 2x4 rails attached to posts
- Pickets attach to structure (not fascia)
- Fascia = cosmetic + clamping layer
- Screws > nails (stronger, repairable)
- Pocket holes > toe-nailing (cleaner + stronger)

---

## ⚡ Mental Model

Posts = skeleton  
2x4 rails = bones  
Pickets = skin  
Fascia = outer finish  

---

## 🔁 Future Repairs

This method allows:
- Easy picket replacement (remove fascia only)
- Rail replacement without full teardown
- Long-term durability vs nailed construction
