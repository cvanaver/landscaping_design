# Claude Code Setup — Landscape Render Project

A one-time setup that turns this folder into a Claude Code project. After this, you can run `claude` from the directory and it will know everything about the project.

## What you'll have when done

- `claude` command available in your terminal
- This project directory configured with a `CLAUDE.md` that loads automatically
- Two Python scripts (`make_mask.py`, `render_landscape.py`) ready to run
- A `requirements.txt` for Python deps
- fal.ai API key configured

## Step 1 — Install Claude Code (~3 min)

On Mac, in Terminal:

```bash
# Requires Node.js 18+. Check version:
node --version

# If you don't have Node or it's < 18, install via Homebrew:
# brew install node

# Install Claude Code globally:
npm install -g @anthropic-ai/claude-code
```

Verify:

```bash
claude --version
```

If you see a version number, you're good.

## Step 2 — Authenticate Claude Code (~1 min)

```bash
claude
```

First run will prompt you to log in via browser. Use the same Anthropic account you use for claude.ai. The login persists across sessions.

Exit with `/exit` or Ctrl+C once authenticated.

## Step 3 — Set up this project directory (~1 min)

Put all the files from this bundle into a single folder:

```
landscape-render/
├── CLAUDE.md
├── SETUP.md                    (this file)
├── requirements.txt
├── render_landscape.py
├── make_mask.py
└── hero.jpg                    (you add this — your yard photo)
```

Then:

```bash
cd path/to/landscape-render
```

## Step 4 — Install Python deps (~30 sec)

```bash
pip install -r requirements.txt
```

If you're on Mac and `pip` isn't recognized, try `pip3` or `python3 -m pip install -r requirements.txt`.

## Step 5 — Set the fal.ai key (~2 min)

1. Sign up at https://fal.ai (Google login works)
2. Go to https://fal.ai/dashboard/keys
3. Create a new key, copy it (starts with `fal-...`)
4. In your terminal:

```bash
export FAL_KEY="fal-your-actual-key-here"
```

To make it stick across terminal sessions, add the line to `~/.zshrc`:

```bash
echo 'export FAL_KEY="fal-your-actual-key-here"' >> ~/.zshrc
source ~/.zshrc
```

Verify:

```bash
echo $FAL_KEY
```

Should print your key.

## Step 6 — Start Claude Code in the project

```bash
cd path/to/landscape-render
claude
```

Claude Code will auto-load `CLAUDE.md` and now knows the project context. You can verify by typing:

```
/memory
```

You should see `CLAUDE.md` listed as a loaded memory file.

## Try it: example prompts

Once `claude` is running in this directory, try these:

> Walk me through running this end to end.

> Generate the mask, then run a single Echinacea render (just one variation, golden hour).

> Add a fourth prompt that renders the same bed in autumn — orange and yellow tones, dried grass plumes, fallen leaves.

> The fence keeps getting changed in the renders. Help me fix the mask.

> How much would 10 variations cost?

Claude Code will read `CLAUDE.md`, understand the project, and execute. It will NOT auto-run the expensive render script — it will ask for confirmation (this is baked into the script and into CLAUDE.md instructions).

## What to do if something breaks

| Problem | Fix |
|---|---|
| `claude: command not found` | Re-run `npm install -g @anthropic-ai/claude-code`; check `npm bin -g` is on your `$PATH` |
| `ModuleNotFoundError: fal_client` | `pip install -r requirements.txt` again, or `python3 -m pip install ...` |
| `FAL_KEY env var is not set` | The export didn't stick. Re-run step 5, or `echo $FAL_KEY` to confirm |
| `tkinter not found` (for `make_mask.py`) | On Mac, install Python from python.org rather than the system one. Or use `brew install python-tk` |
| Claude Code doesn't seem to know about the project | Run `/memory` inside `claude` to verify `CLAUDE.md` is loaded. If not, you're not in the right directory. `pwd` to check. |

## What this bundle does NOT include

- Your yard photo (`hero.jpg`) — you provide this
- Your fal.ai API key — you provide this
- Generated renders — created at runtime in `./renders/`
- The mask — generated by you running `make_mask.py`
